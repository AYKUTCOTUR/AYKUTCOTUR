## 🔧 Featured Project

### Phoenix Net Generator

**Engineer-in-the-loop semantic schematic automation for Altium Designer.**

Phoenix Net Generator analyzes schematic component pins, parses multifunction pin names, allows the engineer to select the intended electrical function, previews structured semantic net names, and generates organized schematic Net Labels.

Instead of silently making electrical design decisions, Phoenix keeps the engineer in control of design intent.

**Current version:** v0.4.4

👉 [View Phoenix Net Generator](https://github.com/AYKUTCOTUR/Phoenix-Net-Generator)
